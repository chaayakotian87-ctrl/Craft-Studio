The execution roadmap

Pick a stage type to filter the list, then mark steps complete.

1

Discovery

Plan

Define the "How Might We" question. Use an empathy map to uncover real pain points before drawing anything. We do not guess; we research.

2

Wireframe

Plan

Sketch low-fidelity, mobile-first layouts in grayscale. Focus on hierarchy and flow. If it does not work in grayscale, colour will not fix it.

3

Semantics

Build

Lay down HTML landmarks: header, nav, main, article and footer. The right element for the right job gives screen readers a table of contents.

4

Style

Build

Apply CSS Grid for the page and Flexbox for components, then the 2025 palette and type. Start with one column and expand using min-width media queries.

5

Logic

Build

Add basic state management and interactivity with JavaScript, such as menus, filters and saved progress, without reaching for a framework.

6

Audit

Verify

Check performance (LCP and CLS) and accessibility against WCAG. Fix what you find, then test again on a real phone.

The standards

Three principles guide every decision in this project.

  • Semantic integrity

    Code for AI and accessibility: meaningful elements, not just divs.

  • 2025 UI/UX compliance

    Warm, grounded aesthetics that move away from sterile tech.

  • Universal access

    Strict WCAG adherence so everyone can use the interface.
